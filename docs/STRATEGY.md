# 原则

公开手册在 `docs-site/`。这一页只保留还在指导代码的原则，不再附十二小时记录。

1. 能量先流进存储，再谈升级。家的操作地板是 `Memory.defense.reserveE`（15000）。W47 用 15000 / 20000 的滞后，以及 25000 的能量软顶。
2. 升级工按喂得饱的数量养。家平常两只 14 WORK。W47 平常两只，40000 连续 500 tick 之后第三只。
3. CPU 账号限额是每 tick 20。桶低于 2000 时战斗和补能优先。外矿防御还要桶至少 3000。
4. 塔和墙做防御。代码不调用安全模式。
5. 外矿只有 W45N8、W45N7、W47N7。再占房间要人决定。
6. 占房、对玩家动手、花钱、开安全模式，都不是脚本自己做的事。
7. `Memory.cmd` 是可选的指挥官。没设置时，角色脚本保持原样。

北极星和「已经做了 / 正在等 / 明确不做」见 `docs-site/plan.md`。2026-11-17 的进度快照见 `docs-site/now.md`。
