# 规划

北极星是至少一只满编的三级远程风筝兵，再加一对负责拆除的搭档。身体是 **4 个 TOUGH、28 个远程、8 个治疗、10 个移动**。强化分别是 XGHO2、XKHO2、XZHO2、XLHO2。孵化加一次强化的能量大约 7740；化合物折成原料大约是氧、氢、催化剂各 1500，再加钾 960、锆 420、瘦 360、铀 120。

选这个目标，是因为远程风筝兵能在塔和治疗都还活着的时候交换伤害，而不是把存储一次性填进一面墙。它很贵。在能量还围着 15000 打转时去做反应链，升级和防御会先饿死。所以顺序是先把垫子做厚，再拉等级，最后才开工业。

## 已经在跑

- 家 W46N8 与 W47N8，两边都按 RCL7 孵化。
- 外矿 W45N8、W45N7、W47N7，以及外矿上的入侵者状态机。
- 家的 link 方案 A，W47 的源 link 和枢纽 link（32,33）。
- 家采氧，W47 采钾并送回家。KO 的反应代码在家，2026-11-17 的快照里旗标是开着的。
- 低 CPU 桶时的执行顺序，以及「绝不自动开安全模式」。

## 正在等

这些等待是门槛，不是未写完的函数。

家里的存储还经常贴着 15000。Boost 要的是抽完能量后仍不低于 20000。快照里家只短暂摸到 20753，大约五十个 tick，门没有因此打开。

W47 的升级工保持两只，要存储连续 500 tick 不低于 40000 才升到三只。摸高 44416 但没停够，闩不合。本地威胁没过期时，就算存储很高，也仍然是两只。

两间房离 RCL8 都还远。7 级控制器的进度总量是 1093.5 万。快照那天家大约每天能走掉十分之一的剩余，W47 大约要再久一倍。这是当时的速度，不是承诺。

## 计划中，还没有自动推进

1. 家的地板稳住，W47 的 40000 闩合上，升级才从「保住控制器」变成「把多余的 WORK 吃完」。
2. 两间房到 RCL8。这一步不新开市场，也不为了矿物再占房间。
3. 能量缓冲朝着大约 10 万走。那是工业可以开始占升级份额的厚度，不是今天的目标。实验室从现在能反应的三座，再到六座、十座。
4. 做出 T3 原料，先备一次风筝兵的库存，再谈能不能持续生产。

反应表里今天只有 KO、LO、UH、OH、ZO、UO。风筝兵要的四级化合物一条都没有。`managers/boost.js` 只会给远程部件填 KO。

## 明确没有开始

- **市场。** 没有下单、没有成交逻辑。终端只用来把 K 送回家，以及在家里的实验室和存储之间挪原料。
- **工厂生产。** `RCL7_INDUSTRY` 是 false。建筑可以已经立在那里，循环没有写。
- **W47 自己反应。** `RCL6_LABS` 是 false。KO 留在家。
- **把固定 filler 换上。** `STATIONARY_FILL` 是 false。女王还在，因为换掉它之前，存储到控制器的搬运和延伸的补充都没有替身。站位仍留在 [布局](/mechanisms/layout)。
- **主动开战、为矿物新占外矿、自动安全模式。** 袭击和征服代码要人把 `Memory.ops` 里的旗标打开才动。手册不把那套步骤写成公开流程。

## 为什么不把实验室提前开满

一座实验室或一座工厂是十几万能量的建筑。在存储还保护 15000 的时候把它们全排进工地，升级工会被工地压到一只，外矿一打架，存储就见底。已经立起来的外壳可以留着。反应只维持家这一条 KO，并且不从 20000 以下的存储里掏 boost 的能量。这样垫子和北极星不会互相拆台。
