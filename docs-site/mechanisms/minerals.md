# 矿物与终端

矿物线是为家里的 KO 准备的，不是为了出售。家的矿是氧，W47 的矿是钾。终端不把能量从一间房发到另一间房。家的 `RCL6_MINERALS`（`src/utils/plan.js`）和 W47 的 `RCL6_MINERALS`（`src/rooms/w47n8/config.js`）都是 true。矿工会孵，终端和萃取器在计划里。家的这道开关还把三座 RCL6 实验室排进去。W47 的实验室是另一道开关 `RCL6_LABS`，现在是 false。

| | 家 W46N8 | W47N8 |
| --- | --- | --- |
| 矿 | 氧。萃取器 **40,24** | 钾。矿物在 **37,45**，那是墙格 |
| 容器和站位 | **41,24** | **37,44** |
| 终端 | 布局在 **35,31** | 布局在 **33,32** |
| 新开一趟的常数 | `MIN_RUN` **1000** | `MIN_RUN` **500** |
| 搬去哪 | 终端，没有终端就进存储 | 只进终端 |

39,23 是家的 RCL7 塔，不是矿物容器。

## 谁在采

两边的身体相同：没有 CARRY，产出掉进脚下的容器。WORK 的个数是 `(能量 - 150) / 100` 的向下取整，再夹在 **2** 和 **12** 之间，后面固定 3 个 MOVE。萃取器不在冷却、矿物还有量，才收割。

### 家

要 **1** 只 `mminer`，得同时满足：控制器至少 **6** 级、这间房有存储、萃取器在、矿物容器在、矿物还有量、容器空位大于 **400**、而且没有被 `mineralCapped` 停住。差一条，目标就是 0。

`Memory.ops.mineralCap = N` 是人在控制台设的刹车。这间房的存储加终端里，**这种**矿物达到 N 就停。别的矿物不算。不设就一直采。写成 0 也等于没设。代码里没有默认数字。这只作用于家里的 `T.mminer`。W47 的孵化不读这个键。存储或终端被别的资源占满时，刹车仍按这种矿物的数量算。氧因此送不走、堆在容器里，容器空位不大于 400，目标才变成 0。

防御地板写在这几条后面。`defLow` 为真时，就算上面算出 1，目标也改成 0。它在墙模块里：`Memory.defense.reserveE` 是一个非 0 的数，并且这间房没有存储，或者存储能量低于这个数。键不在，或写成 0，`defLow` 为假。殖民地把键设在 **15000**。能量正好是 15000 时，地板是松开的。搬运工在地板以下不再新开矿物趟，见 [搬运](/mechanisms/haul)。

回收要这一拍两件事一起成立：`roleTargets.mminer` 是 0（没写过也当成 0），并且 `defLow` 为假。成立了，才走向这间房的一座出生点，挨着了回收。这间房没有出生点，这一拍就停着。`defLow` 为真时，目标即使是 0，人也留在 **41,24**。萃取器在、不在冷却、矿物量大于 0，就继续收。这三件过了才动手。目标是 0 时，下一只不孵。

身体已经付过了。矿工不从存储取能量，只把氧放进脚下的容器。地板守的是塔要用的那一截能量：新的开销先停，已经付过的这只继续把氧放进容器。搬运工在地板以下不再来取，容器就先积着。库存到了上限、容器空位不大于 400、萃取器不在、容器或存储不在、矿物量为 0，都会把目标写成 0。这些和地板叠在同一拍时，人仍留着。地板松开、记下的目标还是 0，才离开容器去回收。出生点不是每一拍都重写这个数。没重写的那一拍，用的是上次的 0 或 1。

矿物量为 0 时，收割停着，目标也是 0。代码不看再生倒计时。量重新大于 0，其它门也开着、并且 `defLow` 为假，目标才回到 1。地板还压着的时候，人站在容器上。

例如储备是 15000，存储是 14900。地板成立，目标写成 0。站在容器上的那只留下，冷却一过继续收氧，下一只不出生。存储回到 15000，氧还有、空位大于 400、这种矿物又没到上限：孵化重算的那一拍把目标写回 1，人留在原地。若回到 15000 时数量已经到了上限，目标仍是 0，这一拍才去回收。

### W47

要孵 `w8mminer`，得 `RCL6_MINERALS` 开着、萃取器在、矿物容器在、矿物还有量、容器空位大于 **400**，并且没有一只寿命高于 **50** 或正在出生的 `w8mminer`。`raidPause`（平民被暂停）时不孵。

它排在经济地板之后。本地矿工和搬运、filler、外矿矿工、预定、防御都在它前面。软顶和盈余升级工在它后面。W47 自己的存储能量低于 `LEAN_ARM`（**15000**），并且外矿搬运短缺时，外矿搬运工插在矿物矿工前面。只数和预算在 [孵化](/mechanisms/spawn)。

W47 不把这只矿工叫回去。容器空位大于 400 只决定要不要再孵。已经站在 37,44 的那只不看空位：萃取器不在冷却、矿物还有量，就继续收。

## 搬进终端

空手时先做矿物还是能量，家的六步在 [搬运](/mechanisms/haul)。这里只记两边门槛差在哪。

还没标上这一趟时，容器里的矿物要不少于 `MIN_RUN` 和这只搬运工携带量里较小的那个，或者容器空位已经不超过 **200**，才新开。空位不超过 200 时先拉走，不必等矿物堆到常数。

家的常数是 **1000**。实验室已经配上时，这只搬运工是 16 CARRY，携带 **800**，门槛就是 800。常数 1000 要携带量也不少于 1000 才等得到。实验室没配上、又处在 link 时期时，身体是 6 CARRY、携带 300，门槛跟着是 300。目的地是终端，没有终端就进存储。`memory.mr` 粘到交货。防御地板以下不再新开，手里已经拿着、并且这一趟已经标上的，要送完。实验室任务排在这趟之后，氧容器才不会一直积着。

W47 的常数是 **500**。本地搬运工满预算是 10 CARRY，携带 **500**，两个数重合。身体更小，就按自己装得下的量走。源码把两边的体型记成大约 400 对 800。按现在的配方，满预算是 500 对 800。目的地只有终端。没有终端，这一趟不做，手里的非能量改送进存储。终端在的时候，手里已经有的非能量也送进终端，不另找存储。从地上、墓碑或废墟捡来的那一份，捡和改送存储写在 [掉落、墓碑和废墟](/mechanisms/salvage)。

钾搬进终端不看 `LEAN_ARM`。存储低于这 15000 只改下面的发送上限。已经在挖的矿工继续挖，已经开了的这一趟也继续送。

## 手续费

W47 的搬运工在 `mineralRun` 之后跑 `termFuel`。发送的手续费从 **终端里的能量** 扣，不从存储扣。这一段负责把能量先放进终端。

`RCL6_MINERALS` 关着，或者终端、存储缺一个，就休眠。终端能量已经到 `TERM_E_FLOOR`（**1000**）也不做。终端里要有至少 **100** 的非能量在等，才去搬。不搬矿物，只搬能量。

身上已经有能量，就送进终端。还是空的，而且没有正在送能量的那一趟，才从存储取。存储能量必须至少 `TERM_FUEL_STOR`（**500**）。以前这道线是 2000，lean 恢复期把第一笔手续费挡住了，才降到 500。500 仍给出生点和塔留一点余量。

1000 能量够相邻房间付好几次 5000 钾的手续费（一次大约 164）。线到了就停，不把存储抽空灌进终端。

## 一次送多少

`mineralSend` 由 W47 的 `layoutRun` **每拍** 调用。目的地写死 **W46N8**。只 `send` 钾（`RESOURCE_KEANIUM`）。氧、KO 和其他矿物可以躺在终端里，这条线不送它们。

批量上限看的是 **W47 自己的存储能量**，不是家的存储。常数是 `LEAN_ARM`，值 **15000**，和搬运、升级页里 W47 的那道紧急线是同一个数。这一页的 15000 是发送批量的分界，不是家的防御地板，也不是实验室的 `ACT_HOME_STOR` 或 `STOR_SAFE`。

| W47 存储能量 | 这一拍的上限 |
| --- | --- |
| 存储不在，或能量是 **0** | **5000**（`SEND_BATCH`） |
| 大于 0，并且小于 15000 | **1000**（`SEND_BATCH_THIN`） |
| 大于或等于 15000 | **5000** |

边界在「大于 0」。能量是 0，或存储还没建好，走 5000，不走 1000。15000 整也走 5000。瘦批量要的是「还有能量，但还没过紧急线」。

上限再和两件事取小：终端里的钾，以及家终端扣掉预留之后剩下的空位。结果少于 `TERM_MIN_SEND`（**100**）就不送。

家终端的空位先减去 `TERM_FREE_TARGET`。它是 **6000**，等于 `TERM_FREE_KO` 的 **1000** 加上 `TERM_FREE_SEND` 的 **5000**：1000 留给一次 KO 从实验室倒回终端，5000 留给下一次从 W47 来的钾。减去之后剩下的不到 100，这一拍是 `homeFull`，一单位都不送。空位不到 **6100** 都会停在这里。

空位够 100 才发，不够就整拍停下。源码注释里记过一次：停放腾出 4300，若按当时的空位把钾送出去，这 4300 会被用完，家终端又紧。4300 减 6000 不够 100，按现在的规则这一拍拒绝。空位是 7000、W47 存储又在 15000 以上、钾也够时，上限虽是 5000，空位只允许多送 1000，所以送 1000，送完还留着 6000。终端里氧和钾各留 3000，是实验室缓冲，和这 6000 空位是两个数。紧和松怎么在终端和存储之间挪，见 [实验室](/mechanisms/labs)。搬运工何时才去做停放，见 [搬运](/mechanisms/haul)。

手续费优先用 `Game.market.calcTransactionCost`。接口不在时，用距离公式 `ceil(数量 × (1 - e^(-距离/30)))`。相邻房间距离是 1：1000 钾是 **33** 能量，5000 钾是 **164** 能量。注释里的「大约 165」是后一笔的约数。能量只看 W47 终端里的能量。不够就把批量减半再算，直到付得起。减到 100 以下就等（`noE`），不欠费发送。例如上限 5000、终端里只有 40 能量时，164、82、41 都付不起，减到 **625**（手续费 21）才送。发送成功才算送出。

这一拍不送时，停在下面第一件成立的理由上：

1. W47 的 `RCL6_MINERALS` 关着。
2. W47 没有终端。
3. `Memory.cmd` 打开，并且这座终端上还有一条活着的指令。没打开时，这道检查是空的。这一阶段的指挥官不调用 `terminal.send`，也没有市场发送。终端为什么只是等着，见 [指挥官接管](/mechanisms/commander)。
4. 终端还在冷却。
5. 终端里的钾少于 100。
6. 家不在视野里，或家没有终端。
7. 家终端空位减去 6000 之后不到 100。
8. 终端能量付不起手续费，批量减到 100 以下。

## 为什么不在 W47 做 KO

W47 的 `RCL6_LABS` 仍是 false。`RCL7_INDUSTRY` 在家的 `plan.js` 和 W47 的配置里都仍是 false。W47 的主循环在布局和塔之后就离开，不调用实验室的 `run`。这些是现在的代码。没有第二道已经写好、等着打开的反应。

家有氧，RCL6 的实验室也排在家里。钾送过一间房，手续费是几十到一百多能量。在殖民地再养一组实验室，还要再写一条搬运。原料在反应发生的那间房会合，家的搬运工只学一种任务。更长的反应链是工业缓冲之后的事。

存储还在紧急线以下时，一次 5000 的手续费大约 164，一次 1000 大约 33。瘦的时候少付，也少把家终端刚腾出的空位一次占满。上限停在 5000，和下一次预留里的那 5000 是同一个数。再加大，6000 的空位就盖不住一次倒出再加一次满批量。

## 没有市场

市场订单是人的决定。机器人默认不下单。`src/` 里 `Game.market` 只出现在 `calcTransactionCost`，用来算手续费。没有 `deal`，没有 `createOrder`，也没有「氧多了就卖掉」的分支。终端的 `send` 只出现在这条钾的线路上。

氧在家里会堆得很高，因为反应消耗的速度远低于采矿。这是预期，不是泄漏。在决定要不要卖、卖多少之前，多出来的氧躺在存储和终端里。市场属于 [规划](/plan) 里「明确没有开始」的那一栏。
