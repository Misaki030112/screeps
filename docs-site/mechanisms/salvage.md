# 掉落、墓碑和废墟

地上的东西会消失。能量每拍都在少，墓碑和废墟过一阵就没了。殖民地会去捡，只捡绕过去之后还划算的那一堆，并且不让矿物把下一趟能量堵住。

规则在 `src/utils/salvage.js`。家的搬运工和家的外矿搬运工用它挑堆。W47 的 `w8hauler` 和 `w8rhauler` 只用它捡矿物战利品，能量堆另有一套。建造工只用里面「这一格走不走得进」。女王不去找堆。

## 怎么打分

人只看脚下这间房。地上的掉落、墓碑和废墟放在一起。别的房间不在这一眼里。

先扣掉别人已经占去的空位。地上的掉落还要再扣路上的衰减：计入的当量除以 1000，向上取整，再乘距离。一格在分数里当作一拍，不另算路和疲劳。墓碑和废墟不扣这一项。扣完还不少于 **50**，才算有一堆。

这一只实际拿得回的，是剩下的量和它自己的空位里较小的那个。这个数要不少于 **50**，再加距离乘 **8**。装不下的部分不帮这趟过线。空位本身不到 50，这一拍不再找，已经记下的也放开。

只有能量时，最远 **25** 格。家里的存储还是自己人的、空位又多于 **1000**，矿物和强化物才计入，每个单位按 **5** 点能量。这种堆最远可以到 **49** 格，也就是一间房的对角。每格的 8 仍然要付。空位装得下的时候，49 格要拿到不少于 442，89 个单位才够，88 个不够。

过了这几道，战利品再加 **1000** 分，排在同样能装满的能量堆前面。矿物不会再长出来，墓碑还会消失。这 1000 加在已经过线的堆上。10 个单位只有 50 点当量，一格外需要 58，仍然不去。12 个单位是 60，一格外才够。

同一间房里，带有还活着的攻击或远程部件的敌人，离这堆不超过 **5** 格，这堆不进新的候选。治疗、WORK 和 CLAIM 不算。斜向也算在这 5 格里。已经记下来的堆不重新量这五格。

地上 80 点能量，人在旁边一格：路上少 1，剩 79，一格要 58，所以去。10 格外先少 10，剩 70，路程要 130，不去。墓碑里同样的 80 不扣衰减，一格外可以去，10 格外还是对不上 130。要走满 25 格，拿到手的得不少于 250。地上 275 的能量路上少 25，剩下正好 250。250 本身先被衰减拿走 25，不够。

## 走不走得进

新的一堆要站得上去。这一格不能在房间边上，x 或 y 是 0 或 49 都不算。不能是地形墙，也不能压着路、容器、城门以外的建筑。八个邻居里还要有一格同样走得过，寻路才迈得进来。

已经在一格以内，这一格就算走得进。RCL7 的印章把从前的 filler 停位 **31,33** 围了起来，人停在两格外只会折返，堆还在每拍减少。邻居都堵死、人又还没贴着的，就不认。

## 一堆按空位来分

堆的 id 记在这只 creep 的 `memory.salv`。`Memory.salv` 说的就是这个键：每只 creep 一份。房间记忆里没有同名的总表。

每一拍有一本临时账。已经记着同一堆的人，从这一拍一开始就把各自的空位加进去。这一拍新看上的，从看上的那一刻起占上，后面的人看得见。账随这一拍丢掉，人身上的 id 还在。账上加的是空位。堆比空位小，第一个人就把整堆盖住。堆比空位大，剩下的还可以再让一个人来。自己占的那一份不会把自己挤掉。

已经贴着、堆里还有计入的量、自己的空位也不少于 50：先捡完，不再跟路程比。还没贴着的，只要这格仍走得进，并且按距离 0 重新算仍过线，就继续走。距离 0 不再加路程，也不再扣衰减。围死了、又还没贴着，就忘掉，回去做原来的活。

墓碑和废墟先取能量。存储还收得下战利品时，能量取完再取数量最多的另一种。这一取之后，计入的存货就空了，或者这一取会把自己装满，认领放开。否则下一拍还回来取剩下的种类。地上的掉落没有存货表，捡的那一拍就放开。没捡完的，下一拍要重新打分才再去。

## 矿物先离开身上

手里有能量以外的资源，先送回家里的存储。一次送一种。存储要在 `memory.home` 指向的房间里，没有这个键就用当前房间。得是自己人的，空位还要多于 1000。人还没挨着，就走过去。挨着了就放进去。这一拍能量的活不做。

没有这样的存储，就把这一种丢在地上，这一拍不因此停住。能量的装卸继续。

家的搬运工要人已经站回家里，才走这一步，而且排在矿物容器、boost、终端和实验室之后。那六步在 [搬运与能量](/mechanisms/haul)。那些步骤没接住的非能量，才由这里送进存储。

W47 的 `w8hauler` 手里已经有矿物时，`RCL6_MINERALS` 开着并且终端在，先送进终端。这一步不做，才改送存储。容器里的钾什么时候新开一趟，在 [矿物与终端](/mechanisms/minerals)。

## 寿命不够就送完

`retire` 看剩余寿命。还没有寿命，或者剩余多于传入的那个数，什么也不做。

还拿着东西：把 `working` 写成真，把身上的送完，不再开新的捡拾。已经空了：走向本房间里最近的出生点，挨着了就回收。身体还没走完的那部分能量回到出生点。这间房没有出生点，就不为了回收离开。

家的搬运工在还没把这一趟标成在送的时候传入 **50**。女王传入 **25**。建造工传入 **1500**。1500 是一整段寿命，剩余不会大于它，所以这道门一直开着。建造工真正要等的是下面那 50 拍空转。

## 谁去捡

### 家的搬运工

矿物、实验室和终端的六步走完，人又在家里，先送身上的矿物。然后若这一趟还没标成在送，看寿命。仍没标成在送，才用这套打分去捡，并且排在固定的矿工容器之前。选中一堆，这一拍就不再等那只容器。

站在容器旁边、顺手捡不少于 25 的地上能量，是另一笔。那一笔在 [搬运与能量](/mechanisms/haul)。

### 女王

女王只在还没把这一趟标成在送的时候看寿命，门槛是 25。她不去找掉落、墓碑或废墟。房间满了，她停在自己的格上，也不扫地上的能量。

走不出去的人，主循环会先解围，任何角色都一样。有空位，就捡脚下或一格以内的能量，放进身边的出生点或延伸，再回收。这是围死格子上的出口。

### 家的外矿

外矿搬运工已经站在自己的外矿房间里、并且 x 不是 0 也不是 49，才用这套打分，而且排在走向容器之前。上下边界没有这道判断。容器旁边两格内、不少于 30 的地上能量是另一笔。

人在家里、寿命不够再跑一趟时，改走家的搬运工，于是也走家的那一套。来回怎么量，在 [外矿与预定](/mechanisms/remotes)。

### 家的建造工

建造工不用这套分。它在家里取能量时，地上和墓碑里不少于 **100** 的能量，并且要走得进，才和枢纽里的几处放在一起比。名单里没有废墟，也不看五格武装。比的是能拿多少除以距离。选中之后，地上的掉落若变得走不进，下一拍就忘掉。墓碑要等能量低于 50 才重选。顺序在 [建造、修理和城墙](/mechanisms/build)。

没有活、存储又在：先把能量倒回存储。倒完仍没有活，空转超过 **50** 拍，才去回收。防御地板以下找不到能量，另一只计数同样超过 50 拍才回收。围城和基金开支不走后一只计数。从外矿改过来的建造工，两只计数都不走。传入的 1500 不构成等待。

### W47

W47 搬能量用的是 `haulPick`。候选里有地上、墓碑、废墟，也有容器。没有建筑类型的那几种按两倍计，容器另有倍数。不扣衰减，也不看五格武装和走不走得进。装到一半就去送。那一套在 [搬运与能量](/mechanisms/haul)。

矿物战利品才回到 `salvage.js`。`w8hauler` 先得站在 W47 里。然后的顺序是：身上的矿物先送走，再按这套分去捡还在衰减的战利品，接着才是矿物容器、终端的手续费，最后才是上面的能量堆。身上的矿物在开关开着、终端也在时送进终端，否则送进存储。这一趟已经标成在送能量，或者空位不到 50，就不再开新的战利品。

`w8rhauler` 手里有矿物，先回 W47，再送进存储。它不走终端那一条。北面的躲避还在生效、身上又没有能量时，先撤回基地，这一拍不送矿物。躲避怎么记，在 [防御与威胁](/mechanisms/defense)。还没开始送、寿命又不低于 **90** 时，先在当前房间按这套分找战利品，再去 W47N7 的能量堆。那边的能量是地上不少于 **100**，或容器不少于 **200**，取最近的。最满的一堆比最近的至少多 500，才改去最满的。寿命低于 90：身上有能量就把这一趟标成去送，空的就自杀，不再开新的能量堆。矿物在这道寿命之前已经往回送。

## 为什么不捡干净

小堆留给衰减。80 点能量走出 10 格，路上少掉的已经盖过值得走的线。人回到容器旁边，房间才有下一趟稳定的能量。

五格里有活的攻击或远程，新的一堆就不选。走进那个范围，丢的是人和身上已经带着的一载。

围死的格子站不进去。人在两格外折返，堆仍在减少。旁边没有能落脚的格子，就换下一件活。已经贴着的人把这一堆收完。

没有还能收的存储时，矿物不计入打分。手里已经有的丢掉，能量的活同一拍继续。

空位先记在这一拍的账上。小堆只盖得住一个人。另一个人回到自己的容器，容器才不会在旁边满出来。堆比一个人体大，剩下的再分。
