# 殖民地手册

这是 Misaki 在 Screeps **shard3** 上的殖民地。家在 **W46N8**，第二间房在 **W47N8**。手册解释代码现在实际在做什么，以及这些选择为什么长成这样。

<ColonyStrip />

它是技术手册，不是宣传页，也不是巡逻日志。库存、升级百分比、某一次战斗的经过，都会过时。能写进正文的，是 `src/` 里的结构和常数。只有 [现状](/now) 收了一份注明日期的快照，用来说明这些常数此刻落在什么位置上。

## 建议的读法

先看 [现状](/now)，确认两间房、能量地板和还没做的事。再看 [规划](/plan)，那一页的图是通向三级风筝兵的顺序。然后按需要进机制：主循环、指挥官、孵化、搬运、掉落、移动、布局、建造、升级、防御、实验室、矿物、Link 与枢纽、外矿、部署。每篇都先讲行为，再讲为什么不换成看起来更猛的做法。

[房间与常数](/reference/rooms) 把坐标和门槛收成一张表，适合已经知道自己在找什么的时候。

右上角可以搜索。中文按字和相邻两字匹配，房间名和 `softCap` 这种标识符按整词匹配。浅色和深色跟随系统，也可以在导航里切换。

## 两套出生点

家和 W47N8 不共用孵化逻辑。`src/main.js` 见到 W47N8 的出生点就交给 `src/rooms/w47n8/`，其余走 `src/managers/spawn.js`。读代码时先分清自己在哪一间房，很多数字只对其中一间成立。

家现在仍是「女王」时期：`STATIONARY_FILL` 关着，没有固定在格子上的 filler 和 manager。延伸和塔由女王从存储补。W47 有自己的 filler、搬运工和升级工，名字都以 `w8` 开头。站位画在哪，见 [布局与印章](/mechanisms/layout)。

## 这里不写的东西

盒子上的监听、数据库、仪表盘和半小时巡逻，留在仓库的运行记录里，不进这本公开手册。令牌、密码、内网地址也不出现。

袭击、征服方阵、探针这些模块在仓库里，默认不武装。手册只说明它们的开关，不写一套出击步骤。
