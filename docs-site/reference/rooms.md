# 房间与常数

数字以 `src/` 为准。能量单位是游戏里的一点能量。tick 是一拍。

## 房间

| | 家 W46N8 | W47N8 |
| --- | --- | --- |
| 出生点 | 35,28；RCL7 的下一座在 30,34 | 15,18 |
| 存储 | 37,31 | 35,32 |
| 源 | 矿工 31,12 与 38,32 | 27,11 站 26,11；11,44 站 11,43 |
| 存储旁的枢纽 link | 37,29 | 32,33 |
| 控制器 link | 30,31 | 13,25 |
| 控制器容器 | 30,30 | 13,26 |
| 矿物 | 氧，矿工位 41,24 | 钾 37,45，容器 37,44 |
| 外矿 | W45N8、W45N7 | W47N7 |

W47 升级工站位是 12,25、14,26、14,27。13,26 留给容器，13,25 是 link，搬运工不从这些站位里穿。

## 能量门

| 常数 | 值 | 管什么 |
| --- | --- | --- |
| `Memory.defense.reserveE` | 殖民地用 15000 | 家的防御地板。墙模块在键缺失时当成 0 |
| 搬运工矿物让路 | `reserveE`，否则 15000 | 低于它，家搬运工不去整理终端 |
| `ACT_HOME_STOR` | 15000 | 实验室观察清单。不直接停止已经装料的反应 |
| `STOR_SAFE` | 20000 | Boost 从存储取能量后必须留下的底 |
| `LEAN_ARM` / `LEAN_STOR` | 15000 / 20000 | W47 leanBank 的重新武装与松开 |
| `LEAN_SOFT_ARM` / `LEAN_SOFT` | 22000 / 25000 | W47 能量软顶的重新武装与清除 |
| `UP_REARM` / `UP_STICKY` | 30000 / 40000 | W47 升级闩。40000 要连续 500 tick |
| 家的第三只升级工 | 地板 + 5000，满 300 tick | 退出大约在地板 + 3000 |
| 后续防御身体 | 家 15000；W47 软顶开着时 25000 | 第一只不看这个 |
| 外矿防御的桶 | 3000 | 低于它不派 |
| 低桶重排 | 2000 | 战斗和补能优先，其余可停一拍 |

## 实验室与终端

| 常数 | 值 |
| --- | --- |
| 每颗远程部件 | 30 KO，20 能量 |
| 实验室 KO 填充目标 | 900，前提是殖民地里够 |
| 输入灌料 / 输出倒出 | 1000 |
| 终端保留的钾、氧 | 各 3000 |
| 家终端要留的空位 | 6000（1000 倒出 + 5000 下一次钾） |
| W47 发送批量 | 存储低于 15000 时 1000，否则 5000；至少 100 |

反应种类：KO、LO、UH、OH、ZO、UO。旗标是 `Memory.ops.labs`，例如家做 KO。

## 默认关着的开关

| 开关 | 现在 |
| --- | --- |
| `STATIONARY_FILL` | false。没有固定 filler |
| `RCL7_INDUSTRY` | false。不自动放工厂和 RCL7 实验室 |
| W47 `RCL6_LABS` | false |
| `Memory.ops.w47n9` | 不设 `on` 就不袭击 |
| `Memory.ops.cq.armed` | 不设 true，征服和方阵不动 |
| `Memory.cmd` | 不设，指挥官不接管 |
| 安全模式 | 代码不调用 |

CPU 账号限额是每 tick 20。上表没有 20，因为源码读的是当场的 `tickLimit`。
